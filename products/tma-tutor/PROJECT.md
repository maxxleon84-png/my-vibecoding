## Название

**«Учим вместе»** — Telegram Mini App репетитор для учеников 2–3 класса.

---

## Что это

Telegram Mini App, которое помогает ученику 2–3 класса самостоятельно разобраться
с темой школьной программы и потренироваться перед контрольной — без родителя рядом.
Ребёнок открывает приложение, выбирает предмет и тему, читает короткое понятное
объяснение и решает задания с разбором каждого ответа.
Родитель платит 149 рублей в месяц и больше не тратит каждый вечер час на домашние уроки.

---

## Для кого

### Плательщик — родитель
- Мама или папа ученика 2–3 класса (дети 7–9 лет)
- Telegram установлен, скачивать ничего не нужно
- Главная боль: нет времени сидеть рядом каждый вечер, репетитор дорого
- Решение принимается быстро — цена 149 руб ниже порога "надо подумать"

### Пользователь — ребёнок
- 7–9 лет, 2 или 3 класс
- Читает и понимает короткий текст
- Может пользоваться смартфоном/планшетом самостоятельно
- Мотивируется значками, стриками, похвалой

### Вторичная аудитория — учитель начальных классов
- Может рекомендовать приложение родителям своих учеников
- Потенциальный канал распространения (реферальная программа для учителей — позже)

---

## Проблема, которую решаем

Репетитор стоит 500–1500 рублей за занятие. У него нужно занимать время заранее.
Родитель не всегда помнит правило безударных гласных в 10 вечера.
Учи.ру — дорого (от 570 руб/мес за один предмет) и перегружено рекламой курсов.
Яндекс Учебник — только задания, нет объяснений, ориентирован на учителя.
Skysmart и Тетрика — живые уроки, нет режима "прямо сейчас, сам".

Итог: на рынке нет доступного инструмента, который объясняет тему по школьной программе
и проверяет знания — так, чтобы ребёнок 7–9 лет справился без взрослого рядом.

---

## Школьная программа (основа контента)

Ориентир: УМК **«Школа России»** — используется в ~65% российских школ.
ФГОС НОО (обновлённый, приказ Минпросвещения №704 от 09.10.2024).

### Предметы и классы MVP

| Предмет | 2 класс | 3 класс |
|---------|---------|---------|
| Математика | Числа до 100, сложение/вычитание, введение умножения | Таблица умножения, деление, задачи, периметр и площадь |
| Русский язык | Безударные гласные, парные согласные, словарные слова | Части речи, состав слова, падежи |
| Окружающий мир | Живая/неживая природа, звёзды, животные, растения | Природные зоны России, тело человека |
| Английский язык | Алфавит, числа, цвета, семья, школа | Животные, одежда, еда, время, дни недели |

Итого: 4 предмета × 2 класса = 8 наборов тем.
Примерно 10 тем на каждый набор = 80 тем.
По 7 заданий на тему = ~560 заданий в базе.

---

## Основные функции MVP

### Для ребёнка

1. **Выбор предмета и темы** — список 4 предметов, внутри список тем. Максимум 3 нажатия до первого задания.

2. **Объяснение темы** — 3–4 коротких абзаца с примерами, написанные на уровне 7–9 лет. Без воды, с конкретными примерами из учебника.

3. **Задания** — 5–7 вопросов с выбором из 4 вариантов. После каждого ответа — объяснение: правильно это или нет и почему.

4. **Результат сессии** — сколько из скольких, что повторить. Поощрение если всё правильно.

5. **Ежедневная серия (стрик)** — счётчик дней подряд. Мотивирует возвращаться каждый день.

6. **Достижения (значки)** — "первое задание", "5 дней подряд", "все темы по математике" и др. Разблокируются автоматически.

### Для родителя

7. **Настройка класса** — один раз выбрать 2 или 3 класс при первом входе.

8. **Подписка через Telegram Stars** — 100 Stars (~149 руб) в месяц. Оплата не выходя из Telegram, автоматическое продление.

9. **Бесплатный уровень** — математика, 5 заданий в день. Родитель может дать попробовать без оплаты.

## Технологии

| Слой | Решение | Почему |
|------|---------|--------|
| Frontend | HTML5 + CSS3 + Vanilla JS | Без фреймворков, быстро, не нужен NPM |
| Telegram SDK | telegram-web-app.js (CDN) | Один script тег, официальный SDK |
| Хранение прогресса | localStorage | Мгновенно, бесплатно, не нужен сервер |
| Хранение подписок | Vercel KV (Redis REST API) | Без NPM — только fetch, free tier 256MB |
| Серверные функции | Vercel Serverless (/api/*.js) | В той же папке проекта, бесплатно |
| Оплата | Telegram Stars (Bot Payments API) | Встроено в Telegram, не нужен эквайринг |
| Хостинг | Vercel | Уже используем в проекте |
| Бот | Уже существующий @maxxleon927bot | Регистрируем TMA в BotFather |

## Чего НЕ будет на старте

| Что | Обоснование |
|-----|-------------|
| Личный кабинет родителя | Требует сервер, авторизацию — сначала проверяем спрос |
| Push-уведомления по расписанию | Нужен бот с cron-логикой — следующий этап |
| Реферальная программа | Сложнее хранение кодов и верификация — после запуска |
| Голосовые объяснения / аудио | Дорогой контент, начинаем с текста |
| Диктанты с вводом текста | Нужен другой тип UI, не типичный для TMA |
| 4, 5 и старшие классы | Сначала проверяем продукт на 2–3 классе |
| Адаптивный алгоритм | Нужна аналитика и история данных — позже |
| Реклама | Доверие родителей важнее монетизации через рекламу |
| Регистрация / логин | Telegram-идентификация достаточна |
| Мобильное приложение (iOS/Android) | Telegram Mini App заменяет его |
