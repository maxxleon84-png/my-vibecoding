# BUILDPLAN.md — Пошаговый план разработки MVP «Учим вместе»

Этот файл — инструкция для разработки. Каждый шаг заканчивается видимым результатом,
который можно открыть в браузере или Telegram и потрогать руками.

---

## Принципы работы

- **Сначала видимый результат, потом детали.** Лучше некрасивое но работающее,
  чем идеальное но ещё не готовое.
- **Один шаг = одна задача.** Не берёмся за следующий пока не проверили текущий.
- **Проверка после каждого шага.** Открываем в браузере, кликаем, смотрим.
- **Комментарии в коде.** Каждый блок кода объяснён — почему именно так.

## Шаг 1 — Визуальная оболочка (index.html + styles.css)

**Цель:** открыть в браузере и увидеть красивый экран приложения.
Никакой логики — только HTML и CSS. Как нарисовать макет на бумаге,
только сразу в браузере.

**Что создаём:**
- `index.html` — все экраны приложения (один показан, остальные скрыты)
- `styles.css` — светлая детская тема, крупный шрифт, цветные карточки

**Экраны в HTML:**
1. `#screen-welcome` — выбор класса при первом запуске (2 или 3)
2. `#screen-home` — главная: стрик, прогресс дня, кнопка "Учиться"
3. `#screen-subjects` — 4 предмета карточками
4. `#screen-topics` — список тем по предмету
5. `#screen-explain` — объяснение темы (текст + кнопка "Понял, поехали!")
6. `#screen-quiz` — вопрос + 4 кнопки ответов
7. `#screen-result` — итог сессии: звёздочки, счёт, кнопки
8. `#screen-paywall` — лимит исчерпан, предложение подписки
9. `#screen-stats` — статистика: прогресс по предметам, достижения

**Проверка после шага 1:**
Открыть `index.html` в браузере → увидеть домашний экран приложения.

## Шаг 2 — База заданий (tasks.js)

**Цель:** написать реальный контент — объяснения тем и задания с ответами.
Это самый важный шаг: без правильного контента приложение бесполезно.

**Что создаём:**
- `tasks.js` — JavaScript-объект со всеми данными

**Структура данных:**
```js
const SUBJECTS = {
  math: {
    id: 'math',
    name: 'Математика',
    emoji: '🔢',
    color: '#2196F3',
    grades: {
      2: [
        {
          id: 'addition-100',
          name: 'Сложение до 100',
          explain: `Текст объяснения...`,  // 3-4 абзаца, язык 7-летнего
          tasks: [
            {
              q: 'Сколько будет 35 + 47?',
              options: ['72', '82', '73', '81'],
              answer: 1,          // индекс правильного ответа
              hint: 'Складываем десятки: 30+40=70. Складываем единицы: 5+7=12. Итого: 70+12=82.'
            }
            // ... 6 ещё заданий
          ]
        }
      ]
    }
  }
}
```

**Контент для MVP (что пишем):**
- Математика 2 класс: 5 тем, 7 заданий каждая = 35 заданий
- Математика 3 класс: 5 тем (таблица умножения и др.) = 35 заданий
- Русский язык 2 класс: 5 тем = 35 заданий
- Русский язык 3 класс: 5 тем = 35 заданий
- Окружающий мир 2 и 3 класс: по 3 темы = 42 задания
- Английский 2 и 3 класс: по 3 темы = 42 задания

Итого MVP: ~224 задания. (Позже расширяем до 560.)

**Правило контента:**
- Объяснение: не более 200 слов, слова как для 7-летнего
- Задания: только из программы "Школа России"
- Каждый hint объясняет ход решения, не просто называет ответ
- Проверить каждый ответ вручную — ни одной ошибки

**Проверка после шага 2:**
Открыть tasks.js в браузере (console.log), убедиться что данные читаются без ошибок.

## Шаг 3 — Логика и навигация (script.js)

**Цель:** приложение "оживает" — можно кликать по экранам, открывать темы,
видеть объяснения и решать задания.

**Что создаём:**
- `script.js` — вся логика приложения

**Блоки кода:**
```
1. Инициализация Telegram SDK
   - tg.ready(), tg.expand()
   - Читаем имя пользователя для приветствия

2. Состояние приложения (state)
   - Загрузка из localStorage
   - Сохранение в localStorage после каждого действия

3. Навигация между экранами
   - showScreen('home') — показывает нужный экран, скрывает остальные
   - История (чтобы кнопка "назад" работала)

4. Выбор предмета и темы
   - Рендер карточек предметов из tasks.js
   - Рендер списка тем по выбранному предмету

5. Объяснение темы
   - Заполнить экран текстом из tasks.js
   - Кнопка "Понял, поехали!"

6. Сессия заданий
   - Взять 5-7 вопросов из выбранной темы
   - Показывать по одному
   - После выбора: подсветить правильный/неправильный
   - Показать hint
   - Кнопка "Следующий"

7. Результат
   - Посчитать правильные
   - Показать звёздочки (1-5 в зависимости от %)
   - Сохранить в прогресс

8. Стрик (серия дней)
   - Проверять дату последнего входа
   - Если сегодня — не обнулять
   - Если вчера — прибавлять +1
   - Если раньше — обнулять до 0

9. Достижения
   - Проверять после каждой сессии
   - Первое задание, 5 дней подряд, все темы математики, и т.д.
   - Toast-уведомление при получении

10. Обновление UI
    - updateHome() — стрик, прогресс дня
    - updateStats() — таблицы прогресса
```

**Проверка после шага 3:**
Открыть в браузере → нажать "Учиться" → выбрать предмет → выбрать тему →
прочитать объяснение → ответить на 5 вопросов → увидеть результат.
Закрыть и открыть снова — стрик должен сохраниться.

## Шаг 5 — Серверная часть: подписка (api/)

**Цель:** принимать реальные платежи Stars и проверять статус подписки.

**Что создаём:**

### api/webhook.js
Этот файл запускается на сервере Vercel когда Telegram присылает обновления.
Два сценария:
1. `pre_checkout_query` — Telegram спрашивает "можем ли мы принять платёж?"
   → отвечаем "да"
2. `successful_payment` — платёж прошёл
   → сохраняем user_id и дату окончания в Vercel KV (Redis)
   → отправляем ребёнку сообщение "Подписка активна!"

### api/check.js
Этот файл проверяет, есть ли у пользователя активная подписка.
Фронтенд отправляет `initData` (это подписанные данные от Telegram),
сервер проверяет подпись (чтобы нельзя было подделать) и смотрит в KV.

**Проверка после шага 5:**
Использовать Telegram тестовый режим → отправить тестовый Stars-платёж →
убедиться что в KV появилась запись → перезайти в TMA → видеть Premium.

## Шаг 6 — Деплой

**Цель:** приложение живёт в интернете и открывается в Telegram.

1. git add + commit + push
2. Создать Vercel-проект с rootDirectory: products/tma-tutor
3. Добавить переменные окружения в Vercel:
   - `BOT_TOKEN` — токен бота
   - `KV_REST_API_URL` — из Vercel KV dashboard
   - `KV_REST_API_TOKEN` — из Vercel KV dashboard
   - `APP_URL` — URL задеплоенного приложения
4. BotFather → @maxxleon927bot → Bot Settings → Menu Button → Set URL
5. Тест: открыть бота в Telegram → нажать кнопку меню

**Проверка после шага 6:**
Открыть @maxxleon927bot в Telegram → нажать кнопку меню → видеть приложение.
Решить задание → получить haptic feedback → стрик работает.
